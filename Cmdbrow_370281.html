界面语言（10 种）

程序当前支持 10 种界面语言，全部在 查看 → 语言 下切换，切换后立即生效，并写入 HKCU\Software\LegacyNotepad\Language（DWORD = 语言枚举值），重启后保持。

覆盖范围

每个语言文件都是完整的 114 条字符串（LangStrings 全字段），覆盖：

  • 7 个顶级菜单与其全部菜单项（含助记符 &、快捷键 \tCtrl+X）
  • 格式 → 编码（5 项）、格式 → 行尾（3 项）
  • 查看 → 图标（3 项）、查看 → 背景（含 13 个位置项）
  • 编译 菜单（编译/强制编译/编译设置/开发库下载）
  • 查找 / 替换 / 转到行 / 透明度对话框所有控件文字
  • 状态栏（Ln/, Col，俄语 Стр/, Стл，德语 Z/, Sp，韩语 줄/, 열，繁体 行/，欄）
  • 关于框文案、各类提示（找不到、保存失败、无法打开/保存）

语言名称本身始终用各自语言写（English / 日本語 / 中文 / Русский / Español / 한국어 / Français / Deutsch / Português / 繁體中文），因此任何界面下都能认出要切哪种。

实现要点

  • LangID 枚举顺序与注册表里已保存的值绑定，新语言只能往后追加，不能插在中间（否则老用户的设置会跳到别的语言）。越界值在 LoadLanguageSetting() 里回落到英语。
  • LangStrings 新增字段一律追加到结构体末尾，因为五个以上语言头文件都是聚合初始化（按位置对齐）；少一条就会整体错位。加完语言后统计各头文件的 ^\s*L" 行数，必须与字段数相等。
  • menu.cpp 里 kLangMenuItems 表是语言菜单的唯一真相来源（ID / LangID / 字符串成员指针），菜单文本与打勾都按 ID 走，不再按位置 ModifyMenuW——位置式在「最近文件」这类运行时插入的菜单里会错位。
  • 切换统一走 main.cpp 的 ApplyUiLanguage()：销毁查找框 → 切语言 → 刷新菜单文本 → 重建最近文件子菜单（标题要跟着换）→ 刷新语言打勾 → 标题 → 状态栏。

加第 11 种语言要改的地方

  1. src\lang\lang.h：LangID 末尾（COUNT 之前）加一项；LangStrings 末尾加 menuLangXXX 字段。
  2. 新建 src\lang\xx.h，字面量条数必须等于结构体字段数（现为 114）。
  3. src\lang\lang.cpp：#include "xx.h" + case LangID::XX:。
  4. src\resource.h：新增 IDM_VIEW_LANG_XX（避开 40100–40199 编译语言区间与 40200 最近文件区间）。
  5. src\notepad.rc：语言子菜单加一项。
  6. src\modules\menu.cpp：kLangMenuItems 加一行。
  7. src\main.cpp：case IDM_VIEW_LANG_XX: ApplyUiLanguage(LangID::XX); break;。
